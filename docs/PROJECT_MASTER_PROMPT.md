## 2. PROJECT IDENTITY

**Project name:** The One Day

**Core philosophy:**

For a long time, I have postponed things I wanted to do because I believed I needed to be more prepared, more skilled, or more confident.

I kept thinking:

"I will do this one day."

This portfolio represents the decision to stop waiting for that perfect day.

Even if I can draw only one line, I will draw it.

Even if I can perform only one yoga asana, I will attempt it.

Even if I can solve only one DSA problem, I will solve it.

Even if I can take only one photograph, I will take it.

Even if I can learn only one technical concept, I will learn it.

The goal is to begin, continue, experiment, and document the journey.

**Core message:**

"You don't need the perfect moment. You just need to begin."

**Supporting thought:**

"One line. One pose. One photograph. One problem solved. One day at a time."

The portfolio should communicate curiosity, creativity, consistency, authenticity, and personal growth.

It should not present me as an expert in everything.

It should present me as a software engineer with multiple interests who is willing to explore them.
